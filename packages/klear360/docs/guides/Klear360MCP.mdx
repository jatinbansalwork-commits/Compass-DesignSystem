<Heading size="xlarge">Klear for AI Agents</Heading>
<Text marginTop="spacing.4" marginBottom="spacing.6">
  Klear360 ships its component, pattern and token documentation for AI coding agents in two forms: the{' '}
  <Text as="span" weight="semibold">Klear360 plugin</Text> (a Claude Code plugin whose skills also load in
  Cursor, Codex, Copilot and Gemini CLI) and the older{' '}
  <Text as="span" weight="semibold">Klear360 MCP</Text> server. Prefer the plugin; the MCP is in maintenance
  mode.
</Text>

<Heading size="large">Klear360 Plugin (recommended)</Heading>

<Heading size="medium">Claude Code</Heading>

From a checkout of the klear360 repository:

```sh
claude --plugin-dir packages/klear360-plugin
```

Marketplace install commands will be published here once the plugin marketplace is live.

<Heading size="medium">Cursor, Codex, Copilot, Gemini CLI</Heading>

```sh
npx skills add klearnow/klear360 --skill klear360
```

The skill lands in `.agents/skills/klear360` (with a `.claude/skills/klear360` symlink). Ask your agent to build UI and it reads the component docs it needs.

The **klear360** skill bundles the docs and guidelines plus workflows for upgrading Klear360 (changelog summaries), scaffolding a Vite + React app and Figma-to-code (klearnow-internal).

<Heading size="large" marginTop="spacing.8">Klear360 MCP (maintenance mode)</Heading>
<Text marginTop="spacing.3" marginBottom="spacing.6">
  Klear360 MCP is a{' '}
  <a href="https://modelcontextprotocol.io/introduction" target="_blank" rel="noreferrer">
    Model Context Protocol (MCP)
  </a>{' '}
  server that exposes the same documentation as tools. Use it only where your agent cannot load skills.
</Text>

<Heading size="large">Setup</Heading>

<Heading size="medium">Cursor</Heading>

Add to `.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "klear360": {
      "command": "npx",
      "args": ["-y", "@klearnow/klear360-mcp@latest"]
    }
  }
}
```

<Heading size="medium">Claude Desktop</Heading>

Add to `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "klear360": {
      "command": "npx",
      "args": ["-y", "@klearnow/klear360-mcp@latest"]
    }
  }
}
```
