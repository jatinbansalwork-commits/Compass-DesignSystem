# General Docs Index

One line per doc. Read `<Name>.md` in this directory.

- **Usage**: Setup (Vite 8 or webpack, UnoCSS, `blade.css`, page defaults, CompassProvider, ToastContainer), the entry points, and the conventions every component follows: callback payloads, bindable values, `children`/`content`, snippets, icons as sources, `class` placement, overlays, toasts and the class lint.
- **Styling**: Compass's token classes for the app's own elements (spacing, colour, type, radius, elevation, motion), what a Compass component's `class` may do, and the rules the class lint enforces.
- **Theming**: Theming through CSS variables over Compass's standard theme, a merchant's brand colour, and the faces.
- **Adapters**: CompassProvider's `adapters`, the app's services: analytics, router, haptics, announcements, locale, errors, toasts, form, dropdown presenter and OTP reader.
- **AvailableIcons**: Every icon `@klearnow/compass-svelte/icons` exports, and how icons are passed.
