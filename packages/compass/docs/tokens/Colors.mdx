# Colors

Compass uses the same Klearnow brand scales in **light** and **dark** mode. Components read semantic tokens (`interactive.background.primary.default`, etc.); `theme.colors.onLight` and `theme.colors.onDark` map those roles to the palette below (dark uses deeper indigo/bluegray surfaces and slightly brighter steps for primary and feedback on charcoal backgrounds).

const swatchBorder = '1px solid rgba(100, 114, 140, 0.28)';

/** Box does not forward `style` or raw hex `backgroundColor` — use a plain div for swatches. */
export const ColorSwatch = ({ color, width = '100%', height = '40px' }) => (
  <div
    style={{
      width,
      height,
      borderRadius: 8,
      border: swatchBorder,
      backgroundColor: color,
      boxSizing: 'border-box',
    }}
  />
);

export const SwatchRow = ({ name, shades }) => (
  <Box marginBottom="spacing.6">
    <Heading size="xsmall" marginBottom="spacing.2">
      {name}
    </Heading>
    <Box display="flex" flexWrap="wrap" gap="spacing.2">
      {shades.map(({ step, hex }) => (
        <Box key={step} width="72px">
          <ColorSwatch color={hex} />
          <Text size="small" color="surface.text.gray.muted">
            {step}
          </Text>
          <Text size="small" color="surface.text.gray.subtle">
            {hex}
          </Text>
        </Box>
      ))}
    </Box>
  </Box>
);

export const SemanticLight = () => {
  const c = compassTheme.colors.onLight;
  const rows = [
    ['Primary button', c.interactive.background.primary.default],
    ['Primary hover', c.interactive.background.primary.highlighted],
    ['Page background', c.surface.background.gray.subtle],
    ['Card surface', c.surface.background.gray.intense],
    ['Body text', c.surface.text.gray.normal],
    ['Muted text', c.surface.text.gray.muted],
    ['Success', c.feedback.background.positive.intense],
    ['Error', c.feedback.background.negative.intense],
    ['Warning', c.feedback.background.notice.intense],
    ['Info', c.feedback.background.information.intense],
  ];
  return (
    <Box display="flex" flexDirection="column" gap="spacing.3" marginBottom="spacing.8">
      <Heading size="small">Light mode — semantic colors (live from theme)</Heading>
      {rows.map(([label, value]) => (
        <Box key={label} display="flex" alignItems="center" gap="spacing.4">
          <ColorSwatch color={value} width="48px" height="28px" />
          <Text size="medium">{label}</Text>
          <Text size="small" color="surface.text.gray.muted">
            {value}
          </Text>
        </Box>
      ))}
    </Box>
  );
};

## Categories

- **interactive** — buttons, inputs, links
- **feedback** — success, error, warning, info
- **surface** — page and container backgrounds, body text
- **overlay** — modal scrims
- **popup** — dropdowns, tooltips
- **data** — chart colors

Every category exists under `theme.colors.onLight` and `theme.colors.onDark`. Toggle **color scheme** in the Storybook toolbar to compare.
